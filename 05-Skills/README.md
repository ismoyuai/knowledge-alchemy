# 05-Skills ·【技能层】

思维模型、SOP、提示词 —— **最值钱的资产**（工具会换，提示词不会）

| | |
|---|---|
| **什么进来** | 思维模型 / SOP / 提示词（一个技能 = 一个目录 + `SKILL.md`） |
| **什么出去** | 被任何 agent 调用；可整套搬到别的工具 |
| **验证方式** | 触发词能唤起；改动后与 agent 技能目录保持同步 |

> 技能靠 `description` 字段触发（`trigger:` 字段不生效）；新技能先放本目录，再同步到 agent 的技能目录。
> 规则全文见根目录 `AGENTS.md`。本文件只说明这个目录自己的职责。
