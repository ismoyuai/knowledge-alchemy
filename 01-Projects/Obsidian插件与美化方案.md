## 3. 效率分析（一句话版）

插件层面能做的提速就三件事：

1. **AI 进库**：Hermes Console——选中文直接问，不切窗口
2. **自动化**：Git 自动提交 + 同步路线——一次配置，长期省事
3. **编辑体验**：Advanced Tables（+ 可选小件）

再往下的提速来自流程本身（agent 干重活），不是插件堆。

## 4. 美化方案

现状：新库 `appearance.json` 是空的（纯默认观感）；旧库是 **Blue Topaz 主题 + 4 个 CSS 片段**（表格样式 / YAML 属性自动隐藏 / Tab / projectCard），另装了 AnuPpuccin 没用过。

| 方案 | 做法 | 观感 |
|---|---|---|
| **A · 延续旧观感** | 从旧库复制 Blue Topaz + 挑 2-3 个片段（0 下载） | 与旧库一致，最稳 |
| **B · 换新风格** | 用本机已有的 AnuPpuccin，或下载 Minimal（极简派） | 全新、更现代 |
| **C · 原生微调** | 不装主题，只调外观设置（深浅色 / 强调色 / 字体 / 行宽） | 最省事，零维护 |

叠加建议（无论选哪套）：

- **表格样式片段**——本库表格比旧库还密，建议带
- **属性区自动隐藏**——每篇开头的属性不占视野
- 字体：有顺眼的中文字体就换（需已装在 Windows 系统里），没有就保持默认
- 点缀（图标/背景）：克制，观感 > 花哨

另说一句实话：美化最大的变量是"少插件"本身——29 个插件的界面 vs 4 个，新库天生就清爽。

## 5. 同步路线（决定 Remotely Save 装不装）

先回答一个问题：**手机端要不要用 Obsidian？**

| 路线 | 适合 | 成本 |
|---|---|---|
| a. 不用手机端 | 灵感在手机上发给 agent（WorkBuddy / 微信），进库在电脑完成 | 0 |
| b. 用手机端 · Remotely Save | 想随时翻库、随手记一笔 | 免费，需配一个云盘（你装过，停用了） |
| c. 用手机端 · 官方 Sync | 要最省心 | 付费 |
| d. 纯 Git 同步 | 不推荐（手机端体验差） | — |
