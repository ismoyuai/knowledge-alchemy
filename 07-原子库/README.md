# 07-原子库 ·【原料层】

原子卡片：**一卡一个概念**，可复用、可组合的最小知识单元。

| | |
|---|---|
| **什么进来** | 过了门禁四问、被挖矿压缩过的单点判断 |
| **什么出去** | 被组合成 `06-Wiki/` 的成篇知识；被 `01` / `02` 直接引用 |
| **验证方式** | 每张卡有红灯（失效场景），且能被别的卡引用 |

> 这里的「原子性」是知识卡片四铁律的第一条：一张卡只承载一个独立知识点。
>
> **入仓闸门**：加工完一条判断先问「什么时候能用」——
> 现在能用 → 直接照做；未来能用 → 才进这里，且**必须写触发条件**（什么情况下取出来用）。
> 规则全文见根目录 `AGENTS.md` 的「第二环的分流闸门」。本文件只说明这个目录自己的职责。
