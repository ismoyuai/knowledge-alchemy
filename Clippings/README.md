# Clippings ·【剪藏层】

网页剪藏

| | |
|---|---|
| **什么进来** | 网页剪藏（外部观点的原文） |
| **什么出去** | 被原子卡 / Wiki 引用，或变成一条灵感 |
| **验证方式** | **30 天未被引用 → 删** |

## ⚠️ 30 天出口规则（强制）

剪藏不是收藏。「收藏有个屁用，点完了就是心里安慰」——所以这里给了硬性出口：

> 入库 30 天内，必须被以下任一动作处理，**否则删除**：
>
> - 被某张原子卡引用 → `07-原子库/`
> - 被某篇 Wiki 引用 → `06-Wiki/`
> - 变成一条灵感 → `00-灵感库/`

**判定标准：没人引用它，它就不该占位置。** 这样剪藏从「仓库」变成「传送带」。

> 剪藏不等于灵感，不许直接进 `00-灵感库/`。规则全文见根目录 `AGENTS.md`。本文件只说明这个目录自己的职责。
